# Mini-Projet de Sélection — Pôle Logiciel
## Robot Étudiant — Recrutement

---

## 1. Contexte et objectif

Ce mini-projet constitue l'étape de sélection pour rejoindre le pôle logiciel du projet de robot étudiant. Il vise à vérifier que vous maîtrisez les bases nécessaires (Python, ROS2) et que vous êtes capable de vous investir de manière autonome et régulière sur une durée courte.

Il ne s'agit pas d'un projet parfait ni complet : ce qui compte est votre démarche, votre progression et votre capacité à livrer quelque chose de fonctionnel dans le temps imparti.

---

## 2. Durée

**à compléter**

---

## 3. Prérequis avant de commencer

Avant de démarrer le mini-projet, vous devez avoir parcouru au minimum :
- Python : bases (variables, fonctions, boucles, classes) — [w3schools.com/python](https://www.w3schools.com/python/default.asp)
- C++ : bases (variables, fonctions, boucles, classes) — [w3schools.com/cpp](https://www.w3schools.com/cpp/default.asp)
- ROS2 : tutoriels officiels jusqu'à *"Writing a simple publisher and subscriber"* en Python **et** en C++ minimum — [docs.ros.org/en/humble/Tutorials.html](https://docs.ros.org/en/humble/Tutorials.html)

### Utilisation de l'IA

Franchement quasi tout est faisable sans, essayez par vous même avant.

L'utilisation d'outils d'IA (ChatGPT, Copilot, Claude, etc.) est **autorisée** pour vous aider à écrire votre code. Cependant, **vous devez être capable d'expliquer chaque partie de votre code lors de l'entretien 1-on-1**. Un code que vous ne comprenez pas ne vous aidera pas à être sélectionné, même s'il fonctionne.
